# Recipe App

A mobile-first recipe application with multi-language support.

## Architecture

- **Tech Stack:** Svelte + SvelteKit
- **Languages:** Catalan, Spanish (Castellano), English, Russian
- **Shared UI Layer:** 60-70% code reuse between web and mobile apps
- **Features:** Recipe management, video/webpage display, custom notes, photo gallery

## Core Features

| Feature | Description |
|---------|-------------|
| **Recipe Management** | Add, modify, archive recipes with external video/webpage URLs |
| **Custom Notes** | User notes per ingredient/instruction step |
| **Photo Gallery** | Tag photos to recipes, native camera access |
| **Localization** | Catalan, Spanish, English, Russian with RTL support |

## Success Metrics

- Time to market: < 4 weeks for web app
- Recipe import: < 30 seconds
- Language switch: < 100ms
- Code sharing: > 90% between platforms
